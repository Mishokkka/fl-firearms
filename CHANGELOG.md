# Changelog

## 0.4.7

- Восстановлена кодировка русского описания и названия языка в manifest.
- Контекст атаки передается в Roll из системного диалога; длительность диалога, сторонние броски и одинаковые NPC-токены больше не нарушают привязку. Parry/rollAction не считается выстрелом.
- Изменения магазинов и общего ресурса координируются одним активным исполнителем через очередь на персонажа; повторные пакеты дедуплицируются, тайм-аут не запускает повтор.
- Последний патрон проверяется и списывается при подтверждении диалога; Push не списывает его повторно. MAG подавляет дополнительную системную проверку Arrows.
- Push-осечка читает pushed/successCount из Roll, а не английский HTML. Отложенное разрешение таблицы действительно ожидается, ошибки не помечаются завершенными.
- Карточки осечки и расхода сохраняют whisper/blind исходного броска. Звук приватной осечки не транслируется всему столу.
- Числовая осечка не зависит от drawn-флагов и не запускает цикл повторных бросков константы; пробелы в таблице показываются диагностикой.
- Миграция сохраняет прежнюю версию при частичном отказе, учитывает synthetic Actors и нормализует новые документы без записи от Observer. API доступен даже при ошибке миграции.
- Inline-поля больше не отправляют два сохранения; переименование затрагивает только кнопки расходников. Read-only controls, UUID окон и сохранность черновика конфигуратора исправлены.
- Добавлены тесты гонок, сокетов, отказов, токенов, приватности и черновиков; CI проверяет синтаксис, JSON и все три набора тестов.

## 0.4.6

- Сведены в один проход дублирующие `renderActorSheet`/`renderApplication` патчи и удалены безусловные retry-таймеры.
- `MutationObserver` больше не реагирует на собственные DOM-вставки магазина и явно отключается при закрытии листа.
- Переименование `Arrows`/`Torches` выполняется одним TreeWalker-проходом вместо двух.
- Удалены два служебных `ChatMessage.setFlag()` на обычный выстрел; идемпотентность сохраняется локальными `WeakSet`.
- Миграции мировых и embedded Items выполняются пакетами с безопасным fallback на поштучное обновление при ошибке batch API.
- Item Sheet не запрашивает второй полный render, если Document update уже вызвал системный render; lazy-normalization коалесцируется на Item.
- Push-listener ставится только на карточки огнестрельных атак.
- Диагностика считает Item-состояния и дубли имен за один проход без промежуточного массива всех Items.
- Fallback сопоставления строк оружия кэширует Item ID и игнорирует текст встроенного счетчика магазина.
- Расширены integration-тесты: batch migration, coalescing ActorSheet render hooks, cleanup observer и отсутствие persisted dedupe-флагов в обычном выстреле.

## 0.4.5

- Источником tooltip оставлен только JournalEntry `Rich Info Tooltips`.
- Удалены перебор альтернативных журналов, настройка имени журнала, нормализация названий и встроенные fallback-описания.
- Страницы журнала индексируются один раз в `Map`; повторные tooltip-запросы выполняются за O(1).
- Кэш автоматически очищается при создании, изменении или удалении журнала и его страниц.

## 0.4.4

- Восстановлен поиск tooltip-описаний свойств в журнале `Rich Info Tooltips` / `Info`.
- Поиск больше не останавливается на первом существующем журнале, если в нём нет нужной страницы.
- Поддерживаются точное и нормализованное совпадение имени страницы, а также оба варианта хранения текста JournalEntryPage в Foundry v13.
- Исправление одновременно возвращает подсказки на Item Sheet и `descriptionHtml` в API для Quick Access.

## 0.4.3

- Исправлен поиск магазинного оружия на Actor Sheet: модуль теперь обрабатывает только строки, реально выведенные системой во вкладке Combat.
- Оружие с MAG в Backpack или Dropped больше не считается потерянной строкой и не участвует в попытке встраивания счетчика.
- Сопоставление выполняется от DOM-строки к Item по `data-item-id` с безопасным fallback по уникальному имени.

## 0.4.2

- Исправлен ложный поиск строк оружия внутри Item Sheet при выборе перезарядки MAG.
- Общий хук `renderApplication` теперь обрабатывает только приложения, собственным документом которых является Actor.
- Поиск оружия на Actor Sheet теперь учитывает `data-item-id` на самой строке, а не только на её дочерних элементах.
- Удалено пользовательское предупреждение «не найден ряд оружия»: отсутствие строки во время частичного рендера является нормальным состоянием и остаётся только в debug-логе.

## 0.4.1

- Возвращена нативно встроенная строка характеристик огнестрела под системными полями оружия.
- Возвращены активные свойства в виде редактируемых чипов с добавлением, удалением и сортировкой.
- Удалён отдельный выделяющийся summary-блок из Item Sheet.
- Исправлен переключатель «Огнестрел»: больше нет `href`, всплытия в системные обработчики и открытия страницы игры.
- Восстановлен старый плоский контракт `getFirearmTooltipData()` для совместимости с FBL Quick Access.
- Ошибки открытия расширенного ApplicationV2-конфигуратора теперь видимы, а не теряются в rejected Promise.

## 0.4.0

### Исправлено

- атака с пустым магазином блокируется до системного броска;
- гонка между списанием последнего патрона и Каморой;
- перезапись единственного pending roll context;
- потеря списания при двух быстрых выстрелах;
- молчаливый отказ при отсутствии rollGear/rollAction;
- молчаливый отказ Push-парсинга;
- неявно полный неинициализированный магазин;
- безусловное переименование расходников всех актеров;
- нормализация каждого Item Sheet без предварительной фильтрации;
- 122 силовых CSS `!important`.

### Добавлено

- очередь контекстов с actor/item matching;
- per-item lock магазина;
- ApplicationV2 Firearm Config;
- ApplicationV2 Diagnostics;
- настройки таблиц, журнала, feedback, debug и initial magazine state;
- доменные `firearm-data.js` и `firearm-rules.js`;
- Handlebars-шаблоны чат-карточек;
- fallback tooltips;
- расширенный API и hooks;
- README, roadmap, test matrix и доменные тесты.

- Item Sheet показывает компактную сводку вместо большого встроенного редактора;
- CSS разделен по областям ответственности;
- `module.json` закреплен за Foundry 13.351 и Forbidden Lands 13.0.5.
