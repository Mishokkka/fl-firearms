## Item Sheet и Quick Access

1. Переключатель «Огнестрел» не меняет URL, не открывает новое окно браузера и не отправляет форму.
2. Строка «Огнестрел / Перезарядка / БП» находится непосредственно под системной строкой Damage/Weight/Category.
3. Активные свойства показаны чипами, их значения редактируются, удаление и добавление работают.
4. Перетаскивание чипов сохраняет порядок.
5. В Quick Access tooltip снова видны тип, перезарядка, БП и свойства огнестрела.

## Регрессии 0.4.7: проверить в живом мире с GM и игроком

Это ручные сценарии, а не утверждение о выполненной проверке в браузерах.

| Сценарий | Проверка |
|---|---|
| Долгий диалог | Держать атаку открытой 2 минуты, бросить ресурс, затем подтвердить атаку: только атака расходует магазин и запускает осечку. |
| Последний патрон | GM и владелец одновременно подтверждают два диалога при 1/6: проходит один выстрел. |
| Две зарядки | Одновременно зарядить два оружия одного персонажа: каждый ресурсный результат применяется к актуальной ступени. |
| Задержанная сеть | Замедлить сеть, повторить клики и перерендерить лист: одна команда, корректное включение кнопки после ответа. |
| Потерянный ответ | Отключить клиента после команды: тайм-аут показывает ошибку и не выполняет команду локально; проверить сохраненное состояние. |
| Смена GM | Два активных GM выбирают одного исполнителя; после выхода исполнителя новые команды идут оставшемуся. Не повторять неподтвержденную команду до проверки состояния. |
| Без GM | Один активный владелец может стрелять и заряжать без GM. |
| Synthetic NPC | Два unlinked токена одного NPC с одинаковым Item ID: расход идет только выбранному токену. |
| Push и локаль | Push с нулем успехов при любом языке системы вызывает осечку; повторный render не повторяет таблицу. |
| Приватность | GM/self/blind бросок: уведомления, breakdown и таблица имеют правильных получателей; звук не раскрывает приватный бросок. |
| Native Arrows | MAG с ammo=arrows: при выстреле нет второй проверки ресурса; обычный лук сохраняет системную проверку. |
| Таблица | Повторная одинаковая осечка работает с replacement=false и drawn=true; отсутствующий диапазон дает явную ошибку без 10 000 попыток. |
| Конфигуратор | Открыть два одноименных embedded Item с одинаковым ID на разных актерах; окна независимы. Изменить поля, заполнить магазин и порядок свойств, сохранить все вместе. |
| Боевой счетчик | Открыть конфигуратор, выстрелить с другого клиента, изменить только свойство: сохранение не возвращает прежние патроны. |
| Наблюдатель | Observer открывает Item/Actor Sheet: контролы записи отключены, миграция не вызывает ошибок прав. |
| Совместимость | Проверить установленный FBL Quick Access и остальные расширения диалога на новом контексте Roll. |

Автоматизированные проверки: `npm run check` и `npm test`. Сокеты в тестах симулируются отдельными экземплярами исполнителя/клиента; настоящий сервер Foundry не входит в Node-тесты.
